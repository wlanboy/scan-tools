Proxy-Scanner

Listet alle Proxy-Einstellungen eines Linux-Systems auf: Umgebung, Shell, apt, yum/dnf, subscription-manager, pip, npm, git, curl, Maven, Docker, Podman und systemd. Für Ubuntu, Debian, RHEL und CentOS.

Bitbucket-Sync

Klont alle Repositories eines Bitbucket-Projekts (Server / Data Center) oder Workspaces (Cloud) bzw. aktualisiert sie per git pull. Parallel, ohne jq, Token nur über Umgebungsvariablen. Grundlage für Massen-Scans.

Forgejo-Sync

Klont alle Repositories einer Forgejo-Organisation oder eines Benutzers bzw. aktualisiert sie per git pull. Funktioniert auch mit Gitea und Codeberg. Parallel, ohne jq, Token nur über Umgebungsvariablen.
